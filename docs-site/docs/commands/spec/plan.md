# prlt spec plan

Generate an implementation plan from a spec.

## Usage

```bash
prlt spec plan <id>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `id` | Spec ID |

## Examples

```bash
prlt spec plan SPC-001
```

This generates a breakdown of tickets needed to implement the specification.
