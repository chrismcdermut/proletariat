# prlt spec list

List all specifications.

## Usage

```bash
prlt spec list [options]
```

## Options

| Flag | Description |
|------|-------------|
| `--type <type>` | Filter by type |
| `--json` | Output JSON |

## Examples

```bash
prlt spec list
prlt spec list --type technical
```
