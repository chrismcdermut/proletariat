# prlt project delete

Delete a project.

## Usage

```bash
prlt project delete <id>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `id` | Project ID |

## Options

| Flag | Description |
|------|-------------|
| `--force` | Skip confirmation |

## Examples

```bash
prlt project delete PRJ-001
prlt project delete PRJ-001 --force
```
