# prlt project list

List all projects.

## Usage

```bash
prlt project list [options]
```

## Options

| Flag | Description |
|------|-------------|
| `--archived` | Show archived projects |
| `--json` | Output JSON |

## Examples

```bash
prlt project list
prlt project list --archived
```
