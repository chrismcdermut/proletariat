# prlt epic move

Move epic status.

## Usage

```bash
prlt epic move <id> [status]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `id` | Epic ID |
| `status` | Target status (draft, active, complete) |

## Examples

```bash
prlt epic move EPC-001 active
prlt epic move EPC-001 complete
```
