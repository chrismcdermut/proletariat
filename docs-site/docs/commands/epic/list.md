# prlt epic list

List all epics.

## Usage

```bash
prlt epic list [options]
```

## Options

| Flag | Description |
|------|-------------|
| `--project <id>` | Filter by project |
| `--status <status>` | Filter by status |
| `--json` | Output JSON |

## Examples

```bash
prlt epic list
prlt epic list --project PRJ-001
prlt epic list --status active
```
