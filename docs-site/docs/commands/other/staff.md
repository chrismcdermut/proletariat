# prlt staff

Manage staff agents.

## Usage

```bash
prlt staff <subcommand>
```

## Subcommands

### staff add

Add staff agents:

```bash
prlt staff add <names...>
prlt staff add alice bob charlie
```

### staff list

List staff agents:

```bash
prlt staff list
```

### staff remove

Remove a staff agent:

```bash
prlt staff remove <name>
```
