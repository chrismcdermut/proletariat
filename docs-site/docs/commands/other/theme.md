# prlt theme

Manage agent naming themes.

## Usage

```bash
prlt theme <subcommand>
```

## Subcommands

### theme list

List available themes:

```bash
prlt theme list
```

### theme set

Set active theme:

```bash
prlt theme set <name>
prlt theme set billionaires
```

### theme create

Create custom theme:

```bash
prlt theme create <name>
prlt theme create mytheme
```

### theme add-names

Add names to theme:

```bash
prlt theme add-names <name>
```
