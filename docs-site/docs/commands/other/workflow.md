# prlt workflow

Manage workflows.

## Usage

```bash
prlt workflow <subcommand>
```

## Subcommands

### workflow list

List workflows:

```bash
prlt workflow list
```

### workflow create

Create a workflow:

```bash
prlt workflow create
```

### workflow view

View workflow details:

```bash
prlt workflow view <id>
```

### workflow switch

Switch active workflow:

```bash
prlt workflow switch <id>
```

### workflow delete

Delete a workflow:

```bash
prlt workflow delete <id>
```
