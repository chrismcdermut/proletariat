# prlt action

Manage actions.

## Usage

```bash
prlt action <subcommand>
```

## Subcommands

### action list

List actions:

```bash
prlt action list
```

### action create

Create an action:

```bash
prlt action create
prlt action create --name "security-audit" --prompt "Review for security..."
```

### action show

Show action details:

```bash
prlt action show <id>
```

### action run

Run an action:

```bash
prlt action run <id>
```

### action update

Update an action:

```bash
prlt action update <id>
```

### action delete

Delete an action:

```bash
prlt action delete <id>
```
