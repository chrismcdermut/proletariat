# prlt claude

Quick ad-hoc Claude session.

## Usage

```bash
prlt claude [prompt]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `prompt` | Optional initial prompt |

## Examples

```bash
prlt claude
prlt claude "explain this error"
```

Starts an interactive Claude Code session without ticket context.
