# prlt session

Manage tmux sessions.

## Usage

```bash
prlt session <subcommand>
```

## Subcommands

### session list

List active sessions:

```bash
prlt session list
```

### session attach

Attach to a session:

```bash
prlt session attach <name>
prlt session attach bold-bezos-1
```
