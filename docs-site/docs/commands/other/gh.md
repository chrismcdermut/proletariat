# prlt gh

GitHub CLI integration.

## Usage

```bash
prlt gh <subcommand>
```

## Subcommands

### gh login

Authenticate with GitHub:

```bash
prlt gh login
```

### gh status

Check authentication status:

```bash
prlt gh status
```

### gh token

Show token setup instructions:

```bash
prlt gh token
```
