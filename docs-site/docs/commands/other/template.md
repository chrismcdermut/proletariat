# prlt template

Manage templates.

## Usage

```bash
prlt template <subcommand>
```

## Subcommands

### template list

List templates:

```bash
prlt template list
```

### template delete

Delete a template:

```bash
prlt template delete <id>
```

### template apply

Apply a template:

```bash
prlt template apply <id>
```

### template save

Save current as template:

```bash
prlt template save
```
