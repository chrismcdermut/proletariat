# prlt board

View the kanban board.

## Usage

```bash
prlt board [options]
```

## Options

| Flag | Description |
|------|-------------|
| `--project <id>` | Filter by project |
| `--json` | Output JSON |

## Examples

```bash
prlt board
prlt board --project PRJ-001
```

## Subcommands

### board watch

Watch board with real-time updates:

```bash
prlt board watch
```
