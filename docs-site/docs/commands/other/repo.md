# prlt repo

Manage repositories.

## Usage

```bash
prlt repo <subcommand>
```

## Subcommands

### repo add

Add a repository:

```bash
prlt repo add <url>
prlt repo add https://github.com/org/repo.git
```

### repo list

List repositories:

```bash
prlt repo list
```

### repo view

View repository details:

```bash
prlt repo view <name>
```

### repo remove

Remove a repository:

```bash
prlt repo remove <name>
```
