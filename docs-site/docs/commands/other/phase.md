# prlt phase

Manage workflow phases.

## Usage

```bash
prlt phase <subcommand>
```

## Subcommands

### phase list

List phases:

```bash
prlt phase list
```

### phase create

Create a phase:

```bash
prlt phase create
```

### phase update

Update a phase:

```bash
prlt phase update <id>
```

### phase move

Reorder a phase:

```bash
prlt phase move <id>
```

### phase delete

Delete a phase:

```bash
prlt phase delete <id>
```
