# prlt status

Manage workflow statuses.

## Usage

```bash
prlt status <subcommand>
```

## Subcommands

### status list

List statuses:

```bash
prlt status list
```

### status create

Create a status:

```bash
prlt status create
```

### status update

Update a status:

```bash
prlt status update <id>
```

### status move

Reorder a status:

```bash
prlt status move <id>
```

### status delete

Delete a status:

```bash
prlt status delete <id>
```
