# prlt execution view

View execution details.

## Usage

```bash
prlt execution view <id>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `id` | Execution ID |

## Examples

```bash
prlt execution view exec-001
```

## Output

```
Execution: exec-001
Agent: bold-bezos-1
Ticket: TKT-001 - Add OAuth
Action: implement
Status: running
Environment: docker
Display: terminal
Started: 5 minutes ago
Tmux: prlt-bold-bezos-1
```
