# prlt agent visit

Navigate to agent workspace.

## Usage

```bash
prlt agent visit <name>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `name` | Agent name |

## Examples

```bash
prlt agent visit alice
# cd's to agents/staff/alice/
```

Prints the path and optionally opens in file manager.
