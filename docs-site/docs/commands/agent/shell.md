# prlt agent shell

Shell into agent workspace.

## Usage

```bash
prlt agent shell <name>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `name` | Agent name |

## Examples

```bash
prlt agent shell alice
prlt agent shell bold-bezos-1
```

Opens an interactive shell in the agent's workspace directory.
