# prlt agent login

Authenticate Claude in agent container.

## Usage

```bash
prlt agent login <name>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `name` | Agent name |

## Examples

```bash
prlt agent login bold-bezos-1
```

Runs `claude login` inside the agent's Docker container.
