# prlt docker list

List Docker containers.

## Usage

```bash
prlt docker list [options]
```

## Options

| Flag | Description |
|------|-------------|
| `--all` | Include stopped containers |
| `--json` | Output JSON |

## Examples

```bash
prlt docker list
prlt docker list --all
```
