# prlt docker shell

Open a shell in a container.

## Usage

```bash
prlt docker shell <name>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `name` | Container/agent name |

## Examples

```bash
prlt docker shell bold-bezos-1
```

Opens an interactive bash shell inside the container.
