# prlt docker sync

Sync files with container.

## Usage

```bash
prlt docker sync <name>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `name` | Container/agent name |

## Examples

```bash
prlt docker sync bold-bezos-1
```

Syncs workspace files between host and container.
