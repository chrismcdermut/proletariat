Agent orchestration for shipping 100x

Spawn, manage, and coordinate AI coding agents to ship 100x. One CLI to rule your entire engineering workflow.

$ npm install -g @proletariat/cli

Features

01

Spawn agents

Spin up AI coding agents in Docker containers with full repo access. Each agent gets its own isolated worktree and environment.

02

Manage work

Track tickets, assign agents, and monitor progress through a unified board. Integrates with Linear, GitHub, and more.

03

Ship faster

Orchestrate multiple agents working in parallel. Auto-merge PRs, resolve conflicts, and keep your pipeline flowing.

How it works

1.
prlt init

Initialize your project with a board, workflow, and agent configuration.

2.
prlt work start

Pick a ticket, spawn an agent, and let it work autonomously in a container.

3.
prlt work propose

Agent creates a PR, runs tests, and moves the ticket to review automatically.
